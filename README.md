
# Tekno NoteBook
**Privacy-First & Fully Local:** Works entirely offline with a focus on privacy, using fully local systems.


Tekno NoteBook is a note-taking application with text-to-speech (TTS), speech recognition, and AI assistant features.

## Features

* **Versatile Note Creation:** Create and add notes with support for multiple formats, including text, code, images, lists, section headings, links, and more.
* **Two Viewing Modes:** Easily switch between reader and editor modes for your notes.
* **Audio Reader Mode:** The reader mode features a media player interface for reading lines of your notes aloud.
* **Auto-Tracking:** Automatically follows and highlights the text currently being played.
* **Smart Line Detection:** Automatically detects the type of a line and creates it accordingly.
* **Fast Writing System:** Supports shortcuts and keyboard keys for a quick and efficient writing experience.
* **Writing Assistant:** Helps with writing, suggests improvements, and checks for spelling and grammar errors.
* **New AI System & Debugger:** Easily create tasks and apply prompt engineering techniques with the new AI system and built-in debugger.
* **Task Creation:** Create tasks to assist the AI and streamline prompt engineering workflows.
* **Smart Integrations:** Fully supports an AI assistant, Text-to-Speech (TTS), and Speech-to-Text (STT).
* **Highly Customizable:** Highly configurable with easily adjustable settings to suit your preferences, including light and dark mode.
* **Math Support:** Math lines with live preview and LaTeX compatibility, including table and LaTeX math line types.
* **Document Import:** Supports PDF, LaTeX, and Markdown formats, including full support for handling images.
* **Export Support:** PDF, LaTeX, and Markdown.
* **Drag Mode:** Easily reorder and organize notes.
* **Table of Contents Navigation:** Available in editor and reader views.
* **And many more!**



## Supported Platforms

* Currently Supported: Windows and Linux (AMD64 architectures).

* Coming Soon: Support for ARM architecture is planned and will be compiled very soon, pending final testing.

## Installation

---

### Install from Snap Store (Canonical)

You can install **Tekno Notebook** via Snap:
```bash
sudo snap install tekno-notebook
````

### Download Tarball


You can also download and install **Tekno Notebook** manually using a tarball:

```bash
# Download
wget https://github.com/FALKONPS/tekno-notebook/releases/download/1.2.26/tekno-notebook-1.2.26.tar.gz

# Extract
tar -xvzf tekno-notebook-1.2.26.tar.gz

# Run
cd tekno-notebook-1.2.26 && tekno-notebook
```
